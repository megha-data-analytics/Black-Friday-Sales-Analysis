# Black Friday Sales Analysis – End-to-End Data Analytics Capstone

## Project Overview

This project is an end-to-end Black Friday Sales Analytics capstone designed to analyze customer purchasing behaviour, product performance, demographic patterns, and sales trends.

The objective is to transform raw retail transaction data into meaningful business insights using Excel, SQL, Python, Statistics, and Power BI.

The project includes data validation, database design, exploratory data analysis, customer-level feature engineering, statistical hypothesis testing, interactive dashboards, and practical business recommendations.

## Dataset Information

- **Dataset:** Black Friday Sales Data
- **Total Transactions:** 550,068
- **Original Columns:** 12
- **Target Variable:** Purchase
- **Analysis Level:** Transaction-level and customer-level analysis

### Key Features

- **Customer Demographics:** Gender, Age, Occupation, Marital Status
- **Geography:** City Category, Stay in Current City Years
- **Product Information:** Product ID, Product Categories
- **Sales Information:** Purchase Amount

### Customer-Level Feature Engineering

The project includes additional analytical features:

- Customer Lifetime Value (CLV)
- Category Breadth
- City Loyalty Index

## Statistical Analysis

The project applies statistical techniques to investigate differences in purchasing behaviour.

| Analysis | Statistical Method | Finding |
|---|---|---|
| Gender | Independent T-test | Significant difference |
| Marital Status | Independent T-test | No statistically significant difference |
| Age Groups | ANOVA | Significant difference |
| City Category | ANOVA | Significant difference |
| City Stay Duration | Correlation | Statistically significant but very weak relationship |

Statistical significance is interpreted separately from practical significance to avoid overstating weak relationships.
